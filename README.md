# 원하는 포즈로 이미지 만드는 도구

## 도구 설명
- 참조 사진에서 사람의 자세(골격)만 뽑아내고, 그 자세를 그대로 유지한 채 원하는 인물·스타일로 새 이미지를 만듭니다. OpenPose로 골격을 추출해 ControlNet 조건으로 넣고 Stable Diffusion 1.5로 생성하며, API 키 없이 무료 Colab GPU에서 동작합니다.

## 사용법
1. `pose_tool.ipynb`를 열고 (colab.research.google.com → 파일 → GitHub 탭에 이 저장소 주소 입력), 런타임 → 런타임 유형 변경 → T4 GPU로 설정합니다.
2. 0~7단계 셀을 위에서부터 순서대로 실행합니다: 설치 → 참조 사진 업로드 → 골격 추출 → 모델 로드 → 한 장 생성 → 조건 바꿔 비교 → 저장. (직접 프롬프트로 시도하려면 6-4단계 셀을 씁니다.)
3. 결과는 `samples/`에 `pose_01.png`(골격)·`output_01.png`(결과) 형태로 저장되고, 마지막 셀을 실행하면 `samples.zip`으로 내려받아집니다.

## 테스트 결과
- 포즈 1: 정면 직립, 한 손만 바지 주머니에 넣은 자세 → 프롬프트: `a young man in a white linen shirt standing in a sunflower field, golden hour` → 결과: 잘 됨 (직립 자세와 주머니에 넣은 손 위치까지 참조와 일치)
- 포즈 2: 다리를 X자로 꼬고 서서 양손을 주머니에 넣은 자세 (프롬프트는 포즈 1과 동일) → 결과: 일부 어긋남 (골격은 정확히 잡혔지만, 생성 결과에서 하체가 배경에 가려지고 상체만 정면 직립으로 나옴)

## 한계
- 손가락이 자주 깨집니다. 한 손에 키포인트가 21개뿐이라 정보가 부족해서이고, `steps`를 25 → 35로 올리면 나아집니다.
- 주머니에 손을 넣거나 팔다리가 사진에서 잘린 경우처럼 몸이 가려지면 키포인트가 일부만 잡히거나 아예 검출에 실패합니다.
- 과제 안내의 FLUX.2-klein 4B 대신 SD 1.5를 씁니다. FLUX 계열은 공개된 OpenPose ControlNet 어댑터가 없어, 검증된 조합을 대신 택했습니다.
